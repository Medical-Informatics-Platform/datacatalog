# Surface: MIP Data Catalog (whole frontend)

Mode: Overview = Persuade-lite; Directory, Explorer, management dialogs = Operate. Direction chosen by user delegation: Opus 5.5 and Gemini 4 Neon advised, merged (they converged on Miller columns, light theme, green brand well, drawers).

## Direction contract

THESIS: Federations are lines, data models are stations, every variable sits at the end of a route you can see. Refuses SaaS dashboard look (hero-metric cards, gradients, glass) and the 950-row tree scroll wall.

OWN-WORLD: Light theme. Ink-tinted-blue neutrals (#12143A text, #F6F7FB canvas, white surfaces, hairline borders), MIP blue #2B33E9 as the line and action colour, #DFEFE4 green brand well flush left in the header holding the blue MIP logo, orange #FFBA08 only as the "you are here" marker. Atkinson Hyperlegible Next + Mono self-hosted; codes always mono. Rows and hairlines, not cards. Shadows only on overlays.

STORY: A researcher sees in seconds that this is a metadata-only catalog of federated hospital networks, scans live network figures, finds a federation, jumps to its data model, narrows 900 variables to one in the column browser, reads its full definition, exports the schema.

FIRST VIEWPORT: White-and-sage header 64px (green brand well + nav). Left 5/12: h1 "What Europe's federated brain-health networks collect, variable by variable.", lead, primary "Explore data models". Right 7/12: live SVG line map (federation lines x model stations, interchange capsules for shared models). Metrics strip with four live numbers directly beneath.

FORM: Transit network map world (assigned by Opus roll, seed: none (pinned by user delegation to advisors)); explorer = column browser with route strip drawing a coloured line from model to selected variable.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
